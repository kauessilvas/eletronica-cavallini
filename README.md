# Eletrônica Cavallini — Landing page

Landing page responsiva em React, Vite e Tailwind CSS.

## Executar localmente

```bash
npm install
npm run dev
```

## Gerar versão de produção

```bash
npm run build
npm run preview
```

Os componentes da página estão agrupados por seção em `src/App.jsx`; estilos globais e utilitários complementares ficam em `src/styles.css`. Os contatos e links de WhatsApp estão definidos no próprio componente para facilitar a manutenção.
